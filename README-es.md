# Portafolio — Kelvin Andrade

Portafolio personal enfocado en desarrollo backend con Python, APIs e integración de sistemas.

**Sitio web:** https://ksaworks.github.io/portfolio_projetos/index-es.html

El sitio presenta mi formación en Análisis y Desarrollo de Sistemas, experiencia laboral y proyectos propios, comerciales y públicos. Los proyectos privados se describen sin publicar código ni datos confidenciales.

## Tecnologías del sitio

- HTML
- CSS responsivo
- JavaScript para navegación móvil
- GitHub Pages

El sitio está disponible en [portugués](index.html), [inglés](index-en.html) y [español](index-es.html).

La versión actual utiliza `assets/css/portfolio-2026.css` y `assets/js/portfolio-2026.js`. Los archivos de versiones anteriores se conservan por compatibilidad.
